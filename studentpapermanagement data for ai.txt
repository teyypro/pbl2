STUDENT DOCUMENT REGISTRATION AND COLLECTION MANAGEMENT SYSTEM
Hệ thống Quản lý Đăng ký và Nhận Giấy tờ Sinh viên
1. GIỚI THIỆU DỰ ÁN
1.1 Tên dự án
Student Document Registration and Collection Management System

(Hệ thống Quản lý Đăng ký và Nhận Giấy tờ Sinh viên)

1.2 Mục tiêu
Xây dựng hệ thống hỗ trợ:

Sinh viên đăng ký các loại giấy tờ trực tuyến.
Nhân viên xử lý hồ sơ duyệt và thực hiện cấp giấy tờ.
Sinh viên lấy số thứ tự nhận giấy tờ tại quầy.
Nhân viên quầy gọi số và trả giấy tờ.
Dashboard thời gian thực hiển thị trạng thái hàng đợi.
Hệ thống được xây dựng bằng:

C++
Lập trình hướng đối tượng (OOP)
Template tự cài đặt
File TXT làm nơi lưu trữ dữ liệu
Kiến trúc 3 Layer
2. PHẠM VI HỆ THỐNG
Hệ thống phục vụ việc:

Cấp giấy xác nhận sinh viên
Giấy xác nhận vay vốn
Bảng điểm
Chứng nhận tốt nghiệp tạm thời
Các loại giấy tờ thuộc Phòng Công Tác Sinh Viên
Các loại giấy tờ thuộc Phòng Đào Tạo
Có 2 phòng tiếp nhận:

Phòng Công Tác Sinh Viên (CTSV)
Phòng Đào Tạo (ĐT)
Mỗi phòng có:

1 quầy nhận giấy tờ
1 hàng đợi riêng

4. CÁC VAI TRÒ HỆ THỐNG

Chức năng:

Xem danh sách giấy tờ
Lập đề nghị cấp giấy tờ

Xem ngày nhận giấy

Xác minh sinh viên

class Request
{
private:
    string requestId;
    string studentId;
    string documentId;

14. TIÊU CHÍ ĐÁNH GIÁ OOP
Áp dụng đầy đủ:

Encapsulation
Thuộc tính private
Getter / Setter
Inheritance
User → Student
User → ProcessingStaff
User → CounterStaff
Polymorphism
Virtual methods:

virtual void showMenu();
Abstraction
Repository và Service hoạt động thông qua interface nghiệp vụ.
